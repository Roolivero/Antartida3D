## Tareas centrales

Solo lo estructural. Los detalles de contenido pendientes se agregan cuando el equipo los defina.

### Hasta H3 — lun 16 nov 23:00 (primer avance)

Objetivo: base técnica cerrada y una expedición recorrible de punta a punta.

- [ ] Elegir prototipo base (`antartida-atlas` o `Lucas`) y congelar el otro como referencia
- [ ] Elegir la primera expedición a desarrollar completa (Orcadas ya tiene fuentes oficiales)
- [ ] Reunir y validar fuentes de esa expedición
- [ ] Implementar el recorrido de esa expedición (explorar → descubrir → profundizar)
- [ ] Publicar en un hosting estático con link público (`npm run build` → `dist/`)
- [ ] Armar un README base con la estructura que piden las bases
- [ ] Redactar el documento de avance: qué está hecho, decisiones, próximos pasos
- [ ] Hacer ≥2 sesiones con el tutor y asistir al taller del eje (H1, H2)

### Hasta H4 — mié 18 nov 21:00 (entrega final)

Objetivo: entregable completo y revisado. No sumar funcionalidades después del 17.

- [ ] Completar las 5 expediciones: Fósiles, Océano, Poncho, Desde Ushuaia, Orcadas
- [ ] Marcar en la interfaz qué es dato real, qué es simulación y qué es reconstrucción
- [ ] Probar en teléfonos físicos y revisar accesibilidad (teclado, foco, contraste)
- [ ] Completar el README: fuentes, licencias, uso de IA, integrantes
- [ ] Grabar el video (≤3 min)
- [ ] Armar las slides (≤5 min), ordenadas según los criterios de evaluación
- [ ] Ensayar el pitch
- [ ] Hacer la entrega antes de las 21:00, con margen de 2 h

### Hasta H6 — vie 20 nov (demo)

- [ ] Confirmar qué ≥2 integrantes van en persona
- [ ] Preparar un plan B sin internet: `dist/` local en una notebook, más un video de respaldo

## Entregables (H4, 18 nov 21:00)

Entrega tardía no se evalúa.

- [ ] Prototipo funcional o demostrable (link, ejecutable, APK, modelo)
- [ ] Repositorio con código fuente
- [ ] README con: problema, eje, solución, instrucciones de uso, tecnologías, fuentes de datos, recursos de terceros y licencias, integrantes
- [ ] Declaración de uso de IA en el README
- [ ] Declaración de ideas preexistentes (si las hay)
- [ ] Video de hasta 3 minutos mostrando funcionamiento
- [ ] Slides para pitch de hasta 5 minutos

| Criterio | Pts |
|----------|-----|
